# Barq OS — Brand Reference

## Name

**Barq OS** is the official product name.

**Barq** comes from the Arabic word **برق**, meaning **lightning**.

Lightning represents speed, instant response, energy, movement, and clarity.

> **Energy in motion.**
>
> **طاقة في حركة.**

## Positioning

Barq OS is a modern Linux operating system designed around gaming, performance, simplicity, freedom, and control.

It has an Arabic identity and is designed for everyone. Arabic identity should appear through naming, language quality, RTL support, release names, and visual character rather than limiting headlines such as “Arabic Gaming Linux.”

## Primary tagline

> **Built for the way you play.**
>
> **مصمم لطريقتك في اللعب.**

## Character

**Fast. Refined. Powerful.**

**سريع. متقن. قوي.**

## Brand pillars

1. **Performance** — responsive and efficient from boot to gameplay.
2. **Play** — gaming is a first-class part of the experience.
3. **Freedom** — Linux and open technologies without ecosystem lock-in.
4. **Control** — a deeply customizable KDE Plasma desktop and ownership of the machine.

## Visual language — Electric Minimalism

Electric Minimalism combines deep dark neutral surfaces, precise geometry, clean typography, generous spacing, restrained electric-blue accents, and short purposeful motion.

Avoid excessive RGB, glow, bloom, bouncing animation, and visual noise.

## Color system

| Token | Value | Role |
|---|---:|---|
| Barq Midnight | `#050814` | Primary dark background |
| Barq Surface | `#0B1220` | Cards and elevated surfaces |
| Barq Blue | `#1A7BFF` | Active state and primary accent |
| Electric Cyan | `#22D7FF` | Motion and secondary highlight |
| Ice | `#EAF2FF` | Text/icons on dark backgrounds |
| Pure White | `#FFFFFF` | High-emphasis neutral |

Target visual balance per screen: ~70% neutral/dark surfaces, ~20% white/ice/neutrals, ~10% Barq Blue/Electric Cyan.

## Typography

- Latin UI/display: **Inter**
- Arabic UI/display: **Noto Sans Arabic** or **IBM Plex Sans Arabic**
- Technical/monospace: **JetBrains Mono**

## Naming rules

Always write **Barq OS**.

Avoid `BARQOS`, `BarqOS`, `BARQ OS`, and `Barq Linux`.

The Arabic form **برق** is a secondary identity element and does not need to appear beside the English name on every screen.

## Release naming

Release names draw from Arabic words connected to light, sky, and motion: Fajr — فجر, Noor — نور, Madar — مدار, Najm — نجم, Sahab — سحاب, and Shorouq — شروق.

Planned first major release: **Barq OS 1.0 — Fajr**.
